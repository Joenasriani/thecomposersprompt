Chapter 3.5: The Prompt Architecture Formula

This chapter offers a practical way to organize a musical brief. It does not describe a model's internal attention order or guarantee that any instruction will be followed.

3.5.1 A Working Prompt Structure

Style + musical character + tempo + instruments + structure + constraints

Use these fields to make your intention clear. Add key, mode, chord movement and rhythmic details where they matter. Their order is a writing choice to test, not a verified weighting formula.

3.5.2 Organizing the Brief

Start with a coherent musical idea, then specify the feature you want to evaluate. For example: piano-led neo-soul, 82 BPM, C major, with a ii–V–I cadence. In C major, ii–V–I means Dm–G–C; sevenths can be added as Dm7–G7–Cmaj7.

No source verified in this edition establishes a fixed Suno order of genre, mood, instrumentation and key. Do not interpret this suggested writing structure as a description of the model's internal processing.

3.5.3 The BPM Energy Bands

Tempo contributes to perceived energy alongside rhythm, density and articulation. The following bands are illustrative groupings, not standardized boundaries for Italian tempo markings or genres:

BPM Range Traditional Marking Common Genres / Character
60–70 Adagio Ballad, ambient, slow R&B
70–90 Andante Lo-fi, downtempo, R&B, indie-folk
90–110 Moderato Pop, indie, hip hop, singer-songwriter
110–130 Allegro Pop-rock, dance, house, upbeat indie
130–150 Vivace Rock, punk, uptempo electronic
150–180+ Presto Drum and bass, metal, hardcore

Specify the beat unit when it matters. For example, “quarter note = 88 BPM” is clearer than a tempo adjective alone. Traditional tempo terms have overlapping interpretations.

3.5.4 Keep the Experiment Interpretable

A primary style with one contrasting detail is a useful starting point because it makes the result easier to evaluate. Hybrid styles are also valid. If a result misses your intention, simplify the brief and change one instruction at a time.

3.5.5 Notation and Audible Description

Try pairing chord symbols with a description of the musical motion. “Dm7–G7–Cmaj7, a ii–V–I arrival in C major” expresses both the chord request and its harmonic function. Neither notation nor descriptive prose guarantees those chords in generated audio.

Compare several outputs from each prompt variant. Listen or transcribe to check the requested notes. An Am9–G13–Cmaj9 request is an experiment: the output may simplify or replace the extensions. Avoid treating a favourable result as proof that a syntax always works.

3.5.6 The Starter Prompt Architecture

A starting template follows. Bracketed chords are experimental instructions, not a verified notation parser; use the appropriate input fields in your chosen tool:

Style: [Genre] + [Mood] + [BPM] + [Key] + [Instruments] + [Production] + [Constraints] Lyrics: [Section tags] + [Bracketed chords] + [Lyrics]

Concrete example:

Style: "Neo-soul, warm and late-night, 82 BPM, E♭ major, Wurlitzer, muted trumpet, brushed drums, walking upright bass, warm analog tape" Lyrics: [Verse] [E♭maj9] … [Cm11] … [A♭maj7] … [B♭13]

The template is the architecture; the theory-specific chapters that follow fill it in.

Chapter 3.5: The Prompt Architecture Formula

Before descending into the specific theoretical categories of Level 1, the student needs a general architecture for how prompts are weighted and structured. This chapter provides the formula, the weighting order, the tempo bands, and the reconciliation of a critical tension: when does notation help, and when does it hurt?

3.5.1 The Universal Formula

From testing across platforms, the reliable formula is:

Genre + Mood + Tempo/BPM + Instruments + Structure + Use Case + Constraints

This formula is the scaffold on which every theory-specific prompt in this book is built. The theory enters at multiple points: Tempo/BPM is a rhythmic specification, Instruments implies timbral and textural categories, Structure implies formal sections and harmonic targets, and Constraints is where key, mode, progression, and voice-leading rules live. But the formula also tells the student what the model weights first: genre and mood.

3.5.2 The Weighting Order

Suno specifically weights in this order:

  1. Genre
  2. Mood/energy
  3. Instrumentation
  4. Musical parameters — key, tempo, time signature

This is critical for theory pedagogy because it means key declaration is not the first thing the model reads; it is the fourth. If the genre and mood are incoherent—"sad happy upbeat ballad" or "classical death metal pop"—the model will average them, and no amount of key specification will save the output. The theory must be embedded in a coherent genre-mood-instrumentation frame.

Stable Audio confirms the same principle: start with genre, name main instruments and rhythmic elements, then describe mood, arrangement, production.

The pedagogical implication is that Theory 101 must be taught alongside a basic literacy in genre and production vocabulary. A student who knows what a Phrygian cadence is but cannot describe a "warm analog production" or a "gated reverb drum" will produce prompts that the model cannot parse. The theory is the fourth layer; the first three layers are the genre, the mood, and the instrumentation.

3.5.3 The BPM Energy Bands

BPM anchors energy. The following bands are a working taxonomy:

BPM Range Traditional Marking Common Genres / Character
60–70 Adagio Ballad, ambient, slow R&B
70–90 Andante Lo-fi, downtempo, R&B, indie-folk
90–110 Moderato Pop, indie, hip hop, singer-songwriter
110–130 Allegro Pop-rock, dance, house, upbeat indie
130–150 Vivace Rock, punk, uptempo electronic
150–180+ Presto Drum and bass, metal, hardcore

The BPM is not a decoration; it is a rhythmic specification that shapes the entire character of the output. A prompt that specifies "88 BPM" is a prompt that specifies a tempo band—Andante, the tempo of walking, the tempo of reflection—not just a number.

3.5.4 The One-Primary-One-Secondary Rule

One primary style + one secondary detail works better than five competing ideas.

A prompt that says "indie-folk, jazz, hip hop, classical, electronic, ambient, with orchestral strings, trap hi-hats, 808 bass, and a sitar" gives the model no coherent frame. It will average across the genres and produce something that sounds like none of them. A prompt that says "indie-folk with a jazz-influenced bridge, fingerpicked acoustic guitar, muted trumpet, brushed drums" gives the model a primary style ("indie-folk") and a secondary detail ("jazz-influenced bridge"). The model can execute the primary style reliably and the secondary detail as a variation.

The pedagogical lesson is that stylistic coherence is a precondition for harmonic specification. A student who specifies a Phrygian mode in a prompt that is stylistically incoherent will get a generic track that may or may not include the ♭2. A student who specifies a Phrygian mode in a prompt that is stylistically coherent ("flamenco-metal, E Phrygian, 95 BPM, nylon-string and distorted guitar") gives the model both the harmonic specification and the stylistic frame in which the harmonic specification makes sense.

3.5.5 The Notation-vs-Feeling Tension, Reconciled

One of the most important findings in the AI music prompt literature is this: "AI tools like Suno generally do not respond well to specific music theory notation. Instead of prompting I-V-vi-IV, prompt the feeling and genre associated with it."

This seems to contradict the approach of this book, which has repeatedly advocated for bracketed chords, Roman numerals, and explicit key declarations. The reconciliation is subtle but important.

The finding is about notation alone. A prompt that says only "I–V–vi–IV in C major" and nothing else—no genre, no instrumentation, no mood—gives the model too little context to interpret the notation. The model does not have a "read Roman numeral" function; it has a statistical association between the string "I-V-vi-IV" and certain audio features. Without the genre and instrumentation context, the association is weak and the model defaults to a generic output.

The finding is not about notation embedded in context. A prompt that says "Pop, C major, 118 BPM, I-V-vi-IV, acoustic guitar + synth pad, bright, verse sparse / chorus layered harmonies" gives the model the notation plus the genre, the tempo, the instrumentation, and the mood. The notation is now a specific constraint within a coherent frame, and the model can execute it reliably.

The pedagogical rule is therefore: notation alone underperforms; notation layered on genre and mood overperforms. A student who learns this rule can use notation confidently, provided they always specify the genre, mood, and instrumentation that give the notation meaning. A student who ignores it will produce prompts that the model cannot parse, and will conclude (incorrectly) that AI "doesn't understand music theory."

The diagnostic question is always: did the notation survive the render? A prompt that specifies [Am9] [G13] [Cmaj9] in a neo-soul context will produce a chord progression that contains those extensions; a prompt that specifies them in a classical context may not. The notation is a control input, and the rendered audio is the evidence of whether the control worked.

A minimal viable prompt for any genre follows this template:

Style: [Genre] + [Mood] + [BPM] + [Key] + [Instruments] + [Production] + [Constraints] Lyrics: [Section tags] + [Bracketed chords] + [Lyrics]

Concrete example:

Style: "Neo-soul, warm and late-night, 82 BPM, E♭ major, Wurlitzer, muted trumpet, brushed drums, walking upright bass, warm analog tape" Lyrics: [Verse] [E♭maj9] … [Cm11] … [A♭maj7] … [B♭13]
