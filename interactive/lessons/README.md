# Chapter inventory and source fidelity

The inventory in `chapter-inventory.json` transcribes chapter titles from the supplied final-cover edition of *The Composer’s Prompt* (158 pages). It is a title-level register, **not a complete verified subsection inventory**. The canonical repository book remains read-only. Chapters 1 and 2 are pilot implementations; Chapter 6.5 is an established working prototype. All other entries remain unimplemented.

Every subsequent lesson must trace its statements, demonstrations, prompts and exercises to the approved book, explicitly flag any supplemental interactive examples, and use shared lesson components. Do not treat title inventory as chapter completion.
