Chapter 24: Negative and Weighted Control

24.1 Separate Prompt Text from Interface Controls

A musical description and a product setting are different inputs. Suno's official Creative Sliders help describes Weirdness, Style Influence and, with an audio upload, Audio Influence. Adjust these in the interface where available. This does not establish typed strings such as style_weight: 0.8 or weirdness_constraint: 0.3 as supported prompt commands.

Source: Suno, How to Use Creative Sliders. Checked 24 October 2026. Availability can vary by mode or account.

The original field names negative_tags, vocal_gender and persona_id are not validated as native prompt syntax in this edition. An API wrapper may use its own field names; consult its documentation before using them in code.

24.2 Describe What to Include and Exclude

Indie-folk in D major, quarter-note tempo 88 BPM. Fingerpicked acoustic guitar and intimate vocal, with a sparse acoustic accompaniment. Avoid distorted electric guitar and electronic drums.

This is a plain-language request. Check the generated arrangement to see whether the exclusions were followed. Where a product provides a dedicated exclusion control, use its documented interface.

24.3 Test One Control at a Time

Keep the prompt fixed and vary one available setting. Record the displayed value and compare several outputs. A single generation cannot isolate the effect of a setting from random variation.

The original Udio examples used a leading minus sign as an exclusion operator. That operator was not verified in this audit; this edition does not teach it as reliable syntax.

Chapter 24: Negative and Weighted Control

24.1 Suno Parameters

  • negative_tags: styles to avoid
  • style_weight (0–1): adherence to the style prompt
  • weirdness_constraint: creative deviation
  • vocal_gender: vocal specification
  • persona_id: cross-song vocal consistency

Complete parameter example:

Style: "Indie-folk, 88 BPM, D major key, fingerpicked guitar, intimate vocals" negative_tags: "distorted guitars, trap hi-hats, electronic drums, autotune, rap" style_weight: 0.8 weirdness_constraint: 0.3 vocal_gender: female

Parameter-specific examples:

Avoiding genre contamination: negative_tags: "metal, punk, EDM, trap, country" Avoiding specific instruments: negative_tags: "saxophone, brass, synth leads" Avoiding production styles: negative_tags: "lo-fi, distorted, muddy, over-compressed" Enforcing genre purity: style_weight: 0.9, weirdness_constraint: 0.1 Encouraging creative deviation: style_weight: 0.5, weirdness_constraint: 0.7

24.2 Udio Syntax

Exclusion example:

"medieval folk, acoustic instruments, -electronic drums, -synthesizer, -electric guitar"

Style weight example:

"indie-folk with tight adherence to genre conventions, -modern pop production, -autotune"

Negative tag example:

"ambient classical, strings and piano only, -percussion, -drums, -rhythm section"
