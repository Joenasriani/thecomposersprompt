Chapter 27: Classroom Exercises

27.1 The Single-Class Exercise

Prompt: Give students a four-bar chorale phrase and a baseline LLM. Task: Write a prompt that causes the model to produce a correct Roman numeral analysis with cadence labels. You may not label the chords yourself.

Student prompt example (strong):

"Analyze this chorale phrase using Roman numerals. Step 1: Determine the key by checking the final chord and the leading tone. Step 2: For each chord, identify the root, quality, and inversion. Step 3: Assign the Roman numeral with inversion figures. Step 4: Name the cadence at the end of the phrase. Phrase: [chord sequence]."

27.2 The Semester-Long Thread

Prompt portfolio example — mode mixture:

Week 1: "What is mode mixture?" Week 4: "Identify all borrowed chords in this progression and label them with their source mode: [progression]." Week 8: "Analyze this passage for modal interchange. For each borrowed chord, identify the source mode, the function of the borrowed chord, and whether it creates a chromatic mediant relationship with the surrounding chords." Week 12: "Compose a 16-bar progression in C major that uses mode mixture from C minor. Annotate each borrowed chord with its source mode and explain its function. Then evaluate whether the progression sounds stylistically plausible for a 19th-century art song."

27.3 The Unified Classroom Exercise

Task 1 (Level 1): Write a Suno prompt that renders the verse with stable triadic/seventh harmony in E minor.

Task 2 (Level 3): Extend the prompt to include the bridge, annotating the secondary dominant and requesting ♭9 color on the B7.

Task 3 (Diagnosis): Analyze the generated output against the specification. Which harmonic constraint was most stable? Which was most fragile? Write a revised prompt that strengthens the weakest constraint.
