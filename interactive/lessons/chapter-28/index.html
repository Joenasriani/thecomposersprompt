Chapter 28: Learning by Teaching

28.1 Teachable Agents

Teachable agent prompt example:

"You are a first-year music theory student. I will teach you about secondary dominants. Ask me questions when you don't understand. At the end, I will test you on a new progression."

Student teaching script:

"A secondary dominant is a dominant seventh chord that tonicizes a scale degree other than the tonic. In C major, A7 is V/ii because it resolves to Dm. Do you understand?"

Teachable agent response:

"I think so, but why is A7 a secondary dominant and not just a borrowed chord?"

Student refinement:

"Good question. A borrowed chord comes from a parallel mode, but a secondary dominant is a chromatic chord that creates a temporary tonicization within the current key. A7 is not borrowed from C minor; it is a dominant seventh built on the second degree that temporarily makes Dm feel like a tonic."

28.2 Error-Seeded Analysis

Error-seeded prompt example:

"Analyze this progression: C–Am–Dm–G–C. Here is my analysis: C is I, Am is vi, Dm is ii, G is IV, C is I. Is my analysis correct? If not, identify the error and explain."

Expected correction:

"There is an error. G is not IV in C major; F is IV. G is V. Your analysis should be: C is I, Am is vi, Dm is ii, G is V, C is I."
