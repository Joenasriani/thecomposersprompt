# Dataset codebook — exact three-CSV candidate

**Classification:** Nonempirical authored symbolic examples. These are not collected audio, participant records, generated outputs, or a statistical sample. All rights to original authored book remain with Joseph Ribal Nasr; dataset licence is UNDECIDED.

## Entity relationships and grain
- `book_derived_six_cases.csv`: **one row per named instructional case** (6 identifiers). Six labels represent **5 distinct chord sequences**, because `CP004` (applied-dominant pair) and `CP006` (matched test) intentionally have the same notes, while differing in pedagogical comparison role.
- `book_derived_48_chord_events.csv`: **one row per (case_id, bar)**, eight per case = 48 rows, **not 48 independent experiments**. `case_id` is foreign key to case CSV, `bar` has values 1–8, `chord` must match the ordered chord in its parent `chord_sequence`. `observed_chord` deliberately BLANK because no audio analysis was performed.
- `book_derived_theme_a_8bar.csv`: **one row per bar in the baseline Theme A** (8 rows). This is a deliberately redundant expanded reference for `CP001`, **not eight extra cases**. Its `roman_numeral` is the harmonic function degree in the *specified* C-major context.

## Column definitions
### Cases CSV
- `case_id` string, CP001–CP006; unique case label, not observation subject.
- `case_name` text; human-readable teaching label.
- `representation` fixed category `written_symbolic_specification`.
- `case_role` teaching comparison role: baseline; multiple_changes; single_chord_change; two_chord_change; matched_control; matched_test.
- `key_center` stated central key, C major.
- `meter` notated meter, 4/4.
- `quarter_note_bpm` integer 96 (specified target, not measured tempo).
- `bar_count` integer 8.
- `chord_sequence` ordered symbols, eight items delimited by vertical bar; one chord per bar.
- `source_pdf_page` integer claimed PDF page locator; inspect source document to confirm locator convention (PDF page vs printed book page). **NOT a stable scholarly citation unless convention is fixed.**
- `observed_audio_status` fixed `NOT_COLLECTED`.

### Chord events CSV
- `case_id` foreign key to case label.
- `bar` 1–8 within case.
- `chord` written chord symbol, not observed transcription.
- `key_center` stated C major.
- `source_pdf_page` case locator, inherited from parent.
- `evidence_type` fixed `book_written_specification`.
- `observed_chord` empty for all rows: observation not collected. Do not substitute a guessed note or `PASS`.

### Theme A CSV
- `example_id` fixed identifier `THEME_A_8`.
- `bar` ordered position 1–8.
- `chord` prescribed triad symbol.
- `key_center` fixed C major.
- `meter` 4/4.
- `quarter_note_bpm` integer 96.
- `roman_numeral` functional degree I, V, vi, IV, I, IV, V, I.
- `source_locator` full book title, chapter 10 section 10.1.
- `evidence_type` fixed `book_specification`.

## Reuse and reproducibility limits
The case files and their 48-position expansion overlap intentionally; users should not add row counts or treat case instances as independent evidence of performance. Chord events can be regenerated by splitting each case's `chord_sequence` and numbering 1–8. Theme A is separately legible as a teaching example. No model, score, MIDI, rendering, transcription, audio annotation, statistical test, or independent expert rating is supplied. All book content and diagram rights remain distinct from the undecided data licence.
